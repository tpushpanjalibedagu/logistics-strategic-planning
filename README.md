# Strategic Planning and Data Exploration in Logistics

## Overview
This repository contains the strategic planning framework and analytical tools designed to optimize last-mile urban delivery logistics. The project addresses rising fuel costs, route inefficiencies, and SLA delays through data science methodologies.

## Key Features
- **KPI Tracking:** On-Time Delivery Rate (OTDR), Cost Per Mile (CPM), and Fleet Capacity Utilization.
- **Clustering:** K-Means clustering algorithm to segment delivery routes into geographic micro-zones.
- **Data Pipeline:** Python-based preprocessing and feature engineering for logistics telemetry data.

## Project Structure
- `main.py`: Core data cleaning, feature engineering, and K-Means clustering pipeline.
- `requirements.txt`: Python package dependencies required to run the project.
